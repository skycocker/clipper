how it works

Two halves, one prompt.

A Flipper plugin reroutes the BLE serial endpoint into a genuine CLI shell; the client bridges your terminal to it. Bytes in, bytes out — that's the whole trick.

install

Up and running in two snips.

1

Put the plugin on the Flipper

Grab clipper-<version>.fap from Releases, drop it on the SD card at /ext/apps/Bluetooth/ (via qFlipper or the mobile app), then launch it from Apps → Bluetooth → CLIpper BLE Shell. The screen reads BLE CLI: ready.

2

Run the client

# macOS — unsigned binary, clear Gatekeeper once
tar -xzf clipper-*-apple-darwin.tar.gz
xattr -dr com.apple.quarantine ./clipper
./clipper

First connect pops a 6-digit numeric-comparison prompt on both the Mac and the Flipper — confirm both. After that it's silent. Then just type:

>: nfc
[nfc]>: scanner
>: storage list /ext     # or anything the Flipper CLI knows

Exit with Ctrl+]. On Linux, pair first with bluetoothctl pair <addr>; Windows is experimental. Prefer source? cd plugin && ufbt launch for the .fap, cd client && cargo run --release for the client.

questions

Things people ask before downloading.

How do I get the Flipper Zero CLI over Bluetooth?

Run the clipper plugin on the Flipper, then run the clipper client on your computer. It pairs over Bluetooth LE and drops you at the Flipper's normal >: prompt — wirelessly. Everything the USB CLI does, clipper does: nfc, subghz, rfid, storage, the interactive sub-shells, all of it.

Isn't this just flipwire?

Same idea — talk to the Flipper over Bluetooth — but where flipwire fires one-shot file commands, clipper gives you the full interactive shell. And clipper is built and tested on macOS, where flipwire's Bluetooth scan doesn't find the device. If you searched "flipwire macOS" and hit a wall, this is for you.

Does it run on my OS?

macOS (Apple Silicon & Intel) is the tested primary target. Linux x86_64 is build- and BLE-scan-verified. Windows compiles in CI and is experimental — reports welcome. One small Rust binary, no runtime to install.

Which firmware do I need? Is Momentum required?

Any firmware with the modern CLI-shell API. Verified on Momentum mntm-012 and official 1.4.x. The plugin is open source, so if your firmware's API differs you can rebuild it with ufbt in seconds.

Is it safe / does it need root or a phone app?

No phone app, no root. It's a standard BLE pairing (6-digit numeric comparison, confirmed on both ends once). The plugin reuses the Flipper's own serial GATT service; the client is a plain userspace binary. All open source under the GPL — read every line.
